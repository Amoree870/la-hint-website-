## مزاد اللوحات — `auction.html`

موقع تفاعلي للمزايدة على لوحات سيارات مميزة، عربي بالكامل (RTL) وبدون أي اعتماد
على صور خارجية — اللوحة السعودية مرسومة بالكامل بـ HTML/CSS.

**المزايا:**

- **لوحات مرسومة بدقة**: شريط `KSA` الأزرق يسارًا، ثم الأرقام، ثم الحروف يمينًا،
  وفي كل نصف سطر عربي وآخر لاتيني (`أ ب ح` ↔ `A B J`) وفق ترتيب اللوحات السعودية.
- **مزايدة لحظية**: نافذة مزايدة فيها الحد الأدنى وخطوة المزاد وأزرار زيادة سريعة
  وسجل للمزايدات.
- **مزايدون آليون**: مزايدات تصل تلقائيًا على لوحات مختارة عشوائيًا (بترجيح للوحات
  القريبة من الانتهاء)، وينبّهك الموقع إن تمت المزايدة عليك.
- **عدّاد تنازلي** لكل لوحة يتغيّر لونه عند اقتراب الانتهاء، مع **تمديد تلقائي**
  دقيقتين لأي مزايدة في اللحظات الأخيرة.
- **بحث وتصفية**: بحث بالأرقام أو الحروف (عربية أو لاتينية)، تصفية حسب عدد الخانات
  أو «مميزة» أو «تنتهي قريبًا» أو المفضلة، وترتيب حسب السعر أو الوقت أو عدد المزايدات.
- **قائمة مفضلة** محفوظة في `localStorage`، و**مظهر داكن/فاتح** محفوظ كذلك.
- **شريط بث مباشر** أعلى الصفحة يعرض آخر المزايدات، وتنبيهات منبثقة (toasts).
- متجاوب حتى عرض 390px، ويحترم `prefers-reduced-motion`.

> جميع اللوحات والمبالغ والمزايدين بيانات تجريبية للعرض فقط (في `src/auction/data.js`).

**نسخة الملف الواحد:** `npm run build:single` ينتج `dist/auction-single.html` — ملف
HTML واحد مدمج فيه كل شيء (الأنماط والسكربت والخطوط كـ `data:` URI)، يُفتح مباشرة
من الجوال أو يُرفع على أي مستضيف ثابت بلا إعداد.

**الملفات:** `auction.html` · `src/auction/main.js` (المنطق) ·
`src/auction/plate.js` (رسم اللوحة) · `src/auction/data.js` (البيانات) ·
`src/auction/style.css` (الأنماط)

## شاشة الملف الشخصي — `index.html`

واجهة جوال لمقهى **La Hint**، مبنية بـ HTML و CSS و JavaScript خام مع **Vite** كأداة تجميع.
التصميم داكن بألوان دافئة، مستوحى من شاشات الملف الشخصي في iOS مع عناصر زجاجية (glassmorphism).

الواجهة **عربية بالكامل (RTL)** ما عدا اسم المقهى `La Hint` فيبقى بالإنجليزية.

## لمحة نخيل القصيم في الهوية البصرية

- **سعف النخيل بدل أكاليل الغار**: الشكلان اللذان يحيطان بالاسم سعفتان مرسومتان
  توليديًا (SVG) بتدرّج ذهبي/تمري، بدل صور الغار الأصلية.
- **نقشة نخيل خافتة** خلف إطار الجوال (شفافية 6٪) تعطي إحساس البستان دون إزعاج بصري.
- **لون ذهبي مستخلص من التمر** (`--gold: #e0bc73`) يظهر في وهج زر الإنجازات وفي أيقونة الكأس.
- **الأرقام بالخط العربي الهندي** (١٥٤ / ٣٦ / ١٢) لاتساق الهوية.
- **زر التبديل** في بطاقة المفضل يمرّ على مشروبات منها *لاتيه التمر السكري*
  و*قهوة عربية بالهيل*.

## التجربة على الآيفون

### الطريقة الأولى: خادم التطوير عبر الشبكة المحلية (تحتاج حاسبًا)

```bash
npm install
npm run dev -- --host
```

يطبع Vite عنوانًا شبيهًا بـ `http://192.168.x.x:5173`. افتحه في Safari على الآيفون
مع بقاء الجهازين على نفس شبكة الواي فاي.

### الطريقة الثانية: GitHub Pages (بلا حاسب)

المستودع فيه `.github/workflows/deploy.yml`. فعّل النشر مرة واحدة:
**Settings → Pages → Source = GitHub Actions**. بعد أول دفعة سيصبح الموقع على
`https://<user>.github.io/la-hint-website-/` وتفتحه من الجوال مباشرة.

### على الجهاز الفعلي

- عند عرض ≤ 500px بلمس، يختفي إطار المحاكاة وتملأ الشاشةُ الجهازَ كتطبيق حقيقي،
  مع احترام المناطق الآمنة (`env(safe-area-inset-*)`) للنوتش وشريط الإيماءة.
- «مشاركة → إضافة إلى الشاشة الرئيسية» يشغّله بملء الشاشة بلا شريط عناوين.
- iOS يشغّل الفيديو تلقائيًا فقط وهو مكتوم (`muted` + `playsinline`، وكلاهما مضبوط).
  في وضع توفير الطاقة يمنعه النظام، ولذلك يعيد `main.js` المحاولة عند أول لمسة.

## الزجاج السائل (`liquid-glass.js`)

لكل عنصر يحمل `data-liquid`:

1. تُقاس أبعاده ونصف قطر حوافه.
2. تُبنى خريطة إزاحة على `<canvas>` باستخدام **دالة المسافة الموقّعة (SDF)** لمستطيل
   مُدوّر الأركان؛ يُخزَّن متجه الانكسار في القناتين `R` و`G` ويتركّز عند الحافة.
3. تُنشأ مرشحات `<feImage> + <feDisplacementMap>` وتُطبَّق عبر
   `backdrop-filter: url(#id) blur(0.3px) saturate(1.3)`.
4. إن لم يدعم المتصفح مرشحات SVG داخل `backdrop-filter` (فايرفوكس/سفاري — ومنها
   Safari على الآيفون) يُكتفى بالتمويه العادي المعرّف في CSS.

### حدّان مقصودان في التنفيذ

- **`minSize: 48`** — العناصر التي يقلّ أصغر أبعادها عن ٤٨px تبقى على تمويه CSS.
  على زر 58×44 يقترب شريط الانكسار من نصف ارتفاع الزر فينقلب الأثر إلى تكبير
  عنيف بحافّة حادّة داخل الزر (رُصد ذلك في كروم فوق واجهة الفيديو). الحبّة
  الكبيرة (225×54) تتجاوز الحد فتحصل على الانكسار الحقيقي.
- **`animation-fill-mode: backwards`** وليس `both` — كل حركة تنتهي عند الحالة
  الطبيعية للعنصر، ولو بقي `transform: translateY(0)` مطبَّقًا بعد الانتهاء
  (وهذا ما يفعله `both`) لرُفع العنصر إلى طبقة تركيب منفصلة فانزاح فضاء
  إحداثيات المرشح وظهرت مستطيلات حادّة داخل الأزرار.

## ملاحظات على الأصول

- **الخطوط**: خطا *Neue Haas Unica* و*Helvetica Now Display* تجاريان وغير مرفقين
  بالمستودع، ولا يغطيان العربية أصلًا. البديل المستخدم هو
  **IBM Plex Sans Arabic** محمّلًا **محليًا** عبر `@fontsource` (يعمل بلا إنترنت)،
  مع بقاء الخطين الأصليين في سلسلة الاحتياط للنص اللاتيني.
- **الأيقونات وسعف النخيل**: أُنتجت كـ **SVG** بدل PNG (أوضح عند أي تكبير وأخف حجمًا)
  وتقع في `public/assets/images/`.
- **الصور البعيدة والفيديو** تُحمَّل من روابطها الأصلية كما هي في المواصفة.

## الاستجابة وإمكانية الوصول

- عرض 440px فأقل: `zoom: 0.6` للإطار، والجسم يلتفّ عند 900px.
- جميع الحركات مُعطَّلة تحت `prefers-reduced-motion: reduce`.
- الأزرار عناصر `button` بتسميات `aria-label` عربية وحلقة تركيز ذهبية.
